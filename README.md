# Voyage 智能旅行定制前端

这是一个面向真实用户体验设计的商业化旅游网站前端，不再展示小组分工、Agent 分工或算法说明。

## 运行方式

直接用浏览器打开：

`C:\Users\朱鼎\Desktop\Front-end\index.html`

## 页面内容

- 商业化首页：首屏大图、旅行搜索、服务亮点。
- 热门目的地：景点卡片、图片展示、城市/类型/关键词筛选。
- 定制行程：自然语言输入、结构化偏好、兴趣标签选择。
- 我的方案：预计花费、匹配度、旅行节奏、每日路线。
- 推荐景点：用用户能理解的方式展示推荐卡片。
- 调整方案：修改预算、节奏、删除景点、添加必去点。
- 用户评价：增强网站真实感与产品感。
